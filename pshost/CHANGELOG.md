# Changelog / Historia zmian

## 0.8.1
- **Fixed / Naprawiono:** a black console window (the plug-in host `pshost_runner.exe`) no longer appears every time a
  filter is started or a plug-in is tested; the host is now a GUI-subsystem program. Czarne okno konsoli
  (`pshost_runner.exe`) nie pojawia się już przy każdym uruchomieniu filtra ani teście wtyczki; host jest teraz
  programem w podsystemie GUI.
- New test guarding this (PE subsystem of the host). Nowy test pilnujący tej poprawki.

## 0.8.0
- First public release: manager window, two-stage plug-in check, filters in *Filters → Photoshop*, restart helper,
  PL/EN interface, installer. Pierwsze publiczne wydanie.
